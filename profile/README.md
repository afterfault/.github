<p align="center"><strong>Simulation infrastructure for the next generation of intelligent systems.</strong></p>

Afterfault builds environments where software teams and AI agents can explore how real systems
behave under failure. Run your application in an isolated environment, introduce crashes, delays and
lost connections, and inspect what happened.

We’re building infrastructure that lets engineers and agents use those environments throughout
development: investigate failures, test changes and carry useful scenarios forward as systems evolve.

Our ambition is to make these environments useful beyond software testing, giving agents better places
to experiment, creating environments used to train the next generation of models and learn as they take
on more complex engineering and research.
