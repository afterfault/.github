<p align="center"><strong>Simulation infrastructure for the next generation of intelligent systems.</strong></p>

Afterfault builds environments where software, and the agents that write it, meet the real world's
failures before the real world does. Agents rebuild the system you already run in an isolated
sandbox, put it through crashes, stalls and lost connections on purpose, and report what actually
happened. A failure found once becomes a test that runs on every change after it.

Our first product sits before the pull request: coding agents and engineers check a change against
real failures where it is written, over MCP or the command line.
